# Versões do CQB Planner

Cada versão abaixo aponta para um arquivo **imutável**, associado ao commit que publicou a respectiva versão. Assim é possível baixar versões antigas individualmente, sem criar branches ou cópias duplicadas do aplicativo.

| Versão | Situação | Arquivo HTML |
| --- | --- | --- |
| **0.1.8 Alpha** · 21/10/2026 | Atual | [Abrir `index.html` da 0.1.8](./index.html) |
| **0.1.7 Alpha** · 20/10/2026 | Histórico | [Abrir `index.html` da 0.1.7](https://github.com/darksource32/CQB-Planner/blob/88f9d73aff1d7639e52a044a0eb428aef0582137/index.html) |
| **0.1.6 Alpha** · 19/10/2026 | Histórico | [Abrir `index.html` da 0.1.6](https://github.com/darksource32/CQB-Planner/blob/57a9eb851ad8def5ffd4440796ec47a107509862/index.html) |

Para baixar uma versão histórica, abra o link correspondente e use **Raw / Download raw file**. Os commits históricos permanecem na linha de ancestrais da `main`, preservando seu conteúdo sem ramificações extras.

Notas de mudanças por versão: [CHANGELOG.md](./CHANGELOG.md).

> **Importante:** `.cqbmap` contém somente a geometria do mapa. Replays e configurações de operadores não são salvos nesses arquivos.
